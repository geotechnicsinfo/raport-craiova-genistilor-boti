# Raport geotehnic orientativ – Str. Geniștilor 581, Craiova

Studiu de birou (fără investigații în amplasament) pentru un teren destinat unei școli: relief și geomorfologie,
geologie (IGR 1:200.000), apă subterană, seismicitate și îngheț, hărți istorice, studii geotehnice de arhivă
din zonă, model geotehnic orientativ, riscuri, recomandări de fundare și programul de investigații propus.

- `index.html` – versiunea în limba română
- `de.html` – versiunea în limba germană (*Orientierender geotechnischer Bericht*)
- `assets/` – figuri (RO / DE) și fondurile hărții interactive (imagini încorporate, fără servicii externe)

Hartă interactivă: Leaflet 1.9.4; fonduri Esri World Imagery, © OpenStreetMap contributors, DSM Copernicus GLO-30,
harta geologică IGR (serviciu INSPIRE). Hărți istorice: Arcanum Maps (vizualizare de bază).

Document orientativ, nu ține loc de studiu geotehnic conform NP 074-2022. Brick Construct · BBC Geotehnic, 25.11.2026.
